# Authoring guide

Use these pages when a documentation change affects ordering, links, rendered
extensions, or published source. Start with ordinary Markdown. Add a supported
extension only when it carries information that prose and standard Markdown
cannot express as clearly.

- [Navigation and links](/authoring/navigation) defines directory indexes, explicit
  reading order, and durable fragments.
- [Authoring extensions](/authoring/extensions) covers tabs, source-backed snippets,
  safe figures, and intended behavior in Plans.
- [Source publication](/authoring/source-publication) defines the opt-in boundary for
  snippet extraction and code browsing.
